# craft-plugins — the ArtCraft plugin catalogue (beta)

This repository is the store for plugins that work in ArtCraft apps (EffectCraft, PhotoCraft,
FigCraft, and more over time). It holds **metadata only**. Plugin files stay on each author's own
GitHub Releases. Every listed release is pinned by SHA-256 and size, so a swapped file is refused.

> Plugins are made by their authors. ArtCraft lists them but does not build, host or guarantee them.

## How it works

| Who | What they do |
|---|---|
| Plugin makers | Register as a vendor once, then open a pull request per plugin or release ([SUBMITTING.md](SUBMITTING.md)) |
| One maintainer | Runs `craft-ext catalogue check`, merges, then `build` + `sign` ([MAINTAINERS.md](MAINTAINERS.md)) |
| Users | Search and install from any app's **Plugins** window, the launcher, or `<app>-cli plugin search` |
| Anyone | Reports a bad plugin with the **Report plugin** issue form |

## Rules for listing

1. **Free and open source only.** Every licence term must be OSI-approved (SPDX), the source must be a
   public GitHub repository, and the plugin must not be paid, trial-limited, licence-key gated or
   otherwise monetised. `catalogue check` enforces the licence and source rules and flags paid wording.
2. **Honest permissions.** Plugins declare what they need; users grant it in each app, and apps
   enforce it on every call. Native (non-sandboxed) plugins carry a "full access to your computer" label.
3. **Your namespace.** `io.github.<you>.<name>` ids must match your GitHub login. Other domains need a
   verified vendor.
4. Listings are refused or removed only for malware, deception, impersonation, illegal content,
   failed checks or broken rules — never for quality or for competing with built-in features.

## Tiers

| Badge | Meaning |
|---|---|
| **Official** | Made by the ArtCraft team |
| **✔ Verified vendor** | A maintainer checked the vendor's identity (verified GitHub organisation domain or a DNS TXT record) |
| **Community** | Any registered vendor whose listing a maintainer allowed |

Apps also label plugins installed from a file as **Not reviewed (local file)**.

## Layout

```text
vendors/<github-login>.toml            vendor registration
plugins/<id>/listing.toml              one per plugin
plugins/<id>/releases/<version>.toml   one per release (generated by `craft-ext pack --release-record`)
revocations.toml                       the kill list
dist/                                  built and signed by a maintainer: index.json(.sig), packages/<id>.json
```

Apps fetch `dist/index.json`, verify its ed25519 signature with the key built into the app, and then
fetch per-package files whose hashes the signed index lists. GitHub stars are fetched at build time
and shown with their date.
